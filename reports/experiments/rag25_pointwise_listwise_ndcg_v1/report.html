Mixedbread pointwise vs FIRST listwise benchmark

Controlled ranking study on 22 RAG25 development narratives

Recommendation

Use the current Mixedbread pointwise reranker for exhaustive pruning, then FIRST listwise reranking only on its final top 100. Preserve per-facet quotas before the global listwise stage because nDCG does not measure answer-evidence diversity.

Design

All methods receive the same original-narrative BM25 top 1,000. Mixedbread scores the complete pool; FIRST applies comparative first-token listwise scoring to Mixedbread's exact top 100 using windows of 20 and stride 10.

Three released Umbrela qrels are kept separate. The paired tests operate across the same 22 topics.

Execution

The RTX 5070 Ti local BF16 smoke scored 8 rows in 6.26 seconds. At its measured 2,825 prompt tokens/second, the 93,312,315-token full organizer pointwise pass would take about 9.2 hours. The cost-guarded A100 path was used for the controlled FIRST treatment.

RAG implication

Ranking quality and evidence diversity are related but distinct. Protect facet quotas before the global reranking cascade, then use the measured winner for final ordering.

Limits

The 2026 test set has no public qrels. These pooled development judgments are not exhaustive, and this experiment isolates ranking from facet candidate generation.
